===========================
How to use 3-say_my_name.py
===========================

This library has one function called ``say_my_name()``.

``say_my_name()`` prints a formatted name string.

::

    >>> say_my_name = __import__('3-say_my_name').say_my_name

Basic usage with both names:

    >>> say_my_name("John", "Smith")
    My name is John Smith

    >>> say_my_name("Walter", "White")
    My name is Walter White

Usage with first name only (default last name):

    >>> say_my_name("Bob")
    My name is Bob 

    >>> say_my_name("Alice")
    My name is Alice 

Empty strings:

    >>> say_my_name("", "")
    My name is  

    >>> say_my_name("John", "")
    My name is John 

    >>> say_my_name("", "Doe")
