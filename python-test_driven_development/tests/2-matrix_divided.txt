===============================
How to use 2-matrix_divided.py
===============================

This library has one function called ``matrix_divided()``.

``matrix_divided()`` divides all elements of a matrix by a given number.

::

    >>> matrix_divided = __import__('2-matrix_divided').matrix_divided

Basic usage:

    >>> matrix = [[1, 2, 3], [4, 5, 6]]
    >>> matrix_divided(matrix, 3)
    [[0.33, 0.67, 1.0], [1.33, 1.67, 2.0]]

    >>> matrix = [[1, 2, 3], [4, 5, 6]]
    >>> print(matrix_divided(matrix, 2))
    [[0.5, 1.0, 1.5], [2.0, 2.5, 3.0]]

Original matrix should not be modified:

    >>> matrix = [[1, 2, 3], [4, 5, 6]]
    >>> new_matrix = matrix_divided(matrix, 2)
    >>> print(matrix)
    [[1, 2, 3], [4, 5, 6]]

With floats:

    >>> matrix = [[1.5, 2.5, 3.5], [4.5, 5.5, 6.5]]
    >>> matrix_divided(matrix, 2)
    [[0.75, 1.25, 1.75], [2.25, 2.75, 3.25]]

Negative numbers:

    >>> matrix = [[-1, -2, -3], [-4, -5, -6]]
    >>> matrix_divided(matrix, -2)
    [[0.5, 1.0, 1.5], [2.0, 2.5, 3.0]]
